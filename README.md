# BrightPath Tuition — Next.js Static Website

A modern, responsive tutoring website for a tutor teaching:

- Primary: Classes 1–5
- Middle School: Classes 6–8
- Online classes
- In-person classes at the tutor's place
- Core/all-primary subjects

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## What to edit

Open `app/page.tsx` and replace:

- BrightPath Tuition → your sister's preferred tuition name
- `+91 99999 99999` → real phone number
- `https://wa.me/919999999999` → real WhatsApp number
- `Your locality, India` → real location
- "Dedicated Tutor" → your sister's name/title
- Subjects, testimonials, timings, and other text as needed

The design uses Framer Motion for smooth entrance/scroll animations and CSS for floating effects and responsive layout.
